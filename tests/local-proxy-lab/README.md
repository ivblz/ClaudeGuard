# Локальные прокси для ClaudeGuard

Это описание локального стенда разработчика, а не встроенная функция ClaudeGuard. Все входы слушают только 127.0.0.1; внешний IP остаётся IP текущей сети Mac. Наличие этих файлов в checkout не означает, что прокси сейчас запущены или профили уже созданы.

Быстрая проверка одним HTTP-прокси: [сайт + Desktop поверх VPN](desktop-web-http.md).

## Выбрать протокол

Из папки ClaudeGuard:

```bash
./tests/local-proxy-lab/use.sh
```

Появится список из 12 протоколов. Введи номер. Или выбери сразу:

```bash
./tests/local-proxy-lab/use.sh socks5
```

Скрипт сохраняет профиль в ClaudeGuard и выбирает режим Proxy. Дождись Proxy OK.
Общий переключатель Protection остаётся в прежнем состоянии.

## Вставить через интерфейс

```bash
./tests/local-proxy-lab/copy.sh https
```

Затем Configure Proxy → ⌘V → OK. JSON-файлы лежат в `profiles/`.

| Имя | Протокол | Порт |
|---|---|---|
| http | HTTP, с авторизацией | 18100 TCP |
| https | HTTPS, с авторизацией | 18101 TCP |
| socks4 | SOCKS4 | 18102 TCP |
| socks4a | SOCKS4a | 18103 TCP |
| socks5 | SOCKS5, с авторизацией | 18104 TCP |
| shadowsocks | Shadowsocks AES-128-GCM | 18105 TCP/UDP |
| vmess | VMess AEAD | 18106 TCP |
| vless | VLESS TCP | 18107 TCP |
| trojan | Trojan TLS | 18108 TCP |
| hysteria2 | Hysteria2 | 18109 UDP |
| tuic | TUIC v5 | 18110 UDP |
| vless-tls | VLESS TLS Vision | 18111 TCP |

TLS-профили содержат CA только этого стенда; системное хранилище доверия не менялось.
Сертификаты действуют до 17 ноября 2026. Приватные ключи и конфиг сервера находятся
в `/tmp/claudeguard-proxy-lab`. Стенд временный, после перезагрузки автоматически не запускается.

Лог:

```bash
tail -f /tmp/claudeguard-proxy-lab/lab.log
```

Остановить / снова запустить:

```bash
./tests/local-proxy-lab/stop.sh
./tests/local-proxy-lab/start.sh
```

В историческом прогоне все 12 протоколов были проверены HTTPS-запросом через отдельный клиент sing-box. Это не подтверждение работы всех протоколов через реальный PF/TUN, браузер и Desktop на любом Mac.
Для TUIC api.ipify.org обрывал TLS, а checkip.amazonaws.com успешно ответил.
Неверное имя TLS-сертификата отдельно проверено и отклонено.
Подробные результаты: `results.json`.

Прежний тестовый прокси на 18080 работает независимо и этими скриптами не останавливается.

Это тестовый стенд, не часть приложения. Скрипты и описание можно коммитить;
сгенерированные профили с тестовыми паролями и manifest.json исключены из Git.

Проверено: 12 протоколов через HTTPS-запросы sing-box. Отдельно реальный Claude CLI
проверен через HTTP/SOCKS5, с выключенной защитой, с разрешённым/запрещённым VPN,
с недоступным прокси и с 70-секундным потоковым ответом локального тестового API.
Это не проверка всех 12 вариантов в реальных сессиях браузера и Desktop.
