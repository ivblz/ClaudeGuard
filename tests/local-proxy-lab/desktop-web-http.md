# Быстрый ручной тест: сайт + Desktop + VPN

Один протокол: HTTP. Нужен уже запущенный локальный тестовый прокси
`127.0.0.1:18080` (отдельный от стенда на портах 18100–18111).
После перезагрузки Mac он может быть не запущен.

## Подготовка

1. Оставь свой VPN включённым. Запомни текущий профиль и режим ClaudeGuard,
   чтобы вернуть их после теста.
2. В ClaudeGuard выбери Proxy → Configure Proxy и вставь:

   ```text
   http://127.0.0.1:18080
   ```

3. Включи Protection, нажми Re-check Now и дождись Proxy OK.
4. Закрой Claude Desktop полностью через ⌘Q и закрой вкладки Claude в браузере.
5. В терминале запусти просмотр только новых подключений к тестовому прокси:

   ```bash
   tail -n 0 -F /tmp/claudeguard-local-proxy/proxy.log
   ```

## Сайт

Открой https://claude.ai в новой вкладке. Если есть действующая сессия,
отправь короткое сообщение. Проверь одновременно:

- страница загрузилась, а при наличии сессии пришёл ответ;
- в терминале появились новые `inbound connection to` с доменами
  `claude.ai`, `anthropic.com` (включая поддомены) или адресами
  `160.79.104.*` / `2607:6bc0:*`;
- VPN остался подключён, другой обычный сайт открывается.

Запросы только к `api.ipify.org` / `checkip.amazonaws.com` — это проверка
ClaudeGuard, они **не подтверждают** проксирование сайта.

## Desktop

Закрой вкладку Claude. Останови просмотр лога через Ctrl+C и снова запусти
ту же команду, чтобы отделить этот этап от предыдущего.
Открой Claude Desktop, дождись загрузки и, если выполнен вход, отправь
короткое сообщение. Проверь те же три пункта: загрузка/ответ, новые
подключения Claude в логе прокси, работающий VPN и обычный сайт.

## Результат

Отметь отдельно `сайт: OK / не OK` и `Desktop: OK / не OK`.
Если приложение открывается, но соответствующих подключений в логе нет,
результат **не подтверждён**: возможно, трафик обошёл прокси.
Ошибка входа не подтверждает исправность чата; проверку ответа в таком случае
отметь как пропущенную.

Это короткий ручной smoke-тест: он не доказывает отсутствие всех утечек
и не проверяет блокировку при обрыве прокси. Локальный прокси использует
текущую сеть Mac, поэтому внешний IP может совпадать с IP твоего VPN.

В конце останови просмотр лога через Ctrl+C и верни прежние настройки
ClaudeGuard. Сам VPN этот тест не переключает.
