ClaudeGuard

VPN whitelist and proxy protection for Claude Code, Claude Desktop and known Claude web destinations.

This installer adds ClaudeGuard to Applications and sets up automatic startup for the current user and a system network protection service. An administrator password is required.

Requirements: macOS 14 or later, Apple Silicon or Intel, and Xcode Command Line Tools (for Python 3). If the tools are not installed, run xcode-select --install in Terminal, wait for installation to finish, then reopen this installer.

Install from the account you will use with ClaudeGuard. Only one protection user per Mac is supported.

The package includes sing-box 1.14.4 for Apple Silicon and Intel; the engine is not downloaded during installation.

On first installation, configure either a VPN whitelist or a proxy profile in the menu bar. Access remains blocked in an unconfigured mode. Existing settings are preserved when upgrading.
